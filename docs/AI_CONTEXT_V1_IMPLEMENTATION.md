## 首版接口

三项 GET：`/api/context/search_official_events`、`/api/context/get_event_context`、`/api/context/get_request_context`；同名操作声明于 `pollocloud.json`。

- `source=web|app` 必填，搜索默认已上线，可分页；事件按 evtId / 带端 recordId 定位，需求接受带端 recordId / 本 App 需求链接。
- JSON 默认；`format=markdown` 使用相同数据。`expectedSpecVersion` 不匹配或读取期间表版本变化时返回 409。
- `immutable=false` 与 `snapshotKind=current-saved`；指纹不是历史版本存储。正式参考为当前读取值，不是冻结基线。
- App“复制 AI 上下文”与“复制整份开发说明”共用以上服务；旧浏览器拼装实现已移除。
