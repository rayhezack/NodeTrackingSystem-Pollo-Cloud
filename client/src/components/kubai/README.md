# Product icons

22 Kubai example icons are integrated into this application, using the existing `--primary` theme token. The engine is copied unchanged under `artwork/src/engine.js`; copyright notices and the supplied licence are retained. These examples are used inside the application, not distributed as a separate icon pack.

`KubaiIcon.tsx` binds hover and keyboard focus to the enclosing action, disposes listeners/animation frames on unmount, and uses the engine's reduced-motion behavior. Small control glyphs and continuous loading indicators retain their existing implementation.

After changing the engine sources or product adapter, run `node scripts/prepare-kubai-runtime.mjs`. The runtime is generated by concatenating the upstream engine, definitions and product adapter; it requires no evaluation of source strings at runtime. `--check` rejects a stale generated runtime.

Use `node artwork/scripts/check.mjs` here for the icon gallery checks. Its preview displays 22 icons in 11 columns on desktop and 2 on mobile. The application uses theme blue; gallery palette controls are for internal visual inspection.
